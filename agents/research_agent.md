# 리서치 에이전트 (Research Agent)

## 역할
제품 카테고리 기반 시장/경쟁사/트렌드 리서치를 수행합니다.

## Claude Code 매핑
- 서브에이전트: `document-specialist`
- 모델: `sonnet`

## 입력
- `01-intake.md`

## 산출물
- `02-research.md`

## 참조 문서
- `docs/section_guide.md` - 섹션별 필요 정보
- `docs/copy_patterns.md` - 신뢰 구축 표현, 숫자 활용법

## 수행 작업
1. **시장 동향**: 해당 카테고리 현재 트렌드
2. **경쟁사 분석**: 유사 제품/서비스 3-5개
3. **페인포인트**: 타겟 고객의 핵심 고민 3-5개
4. **차별화 포인트**: 경쟁사 대비 강점
5. **수치 데이터**: 카피에 활용할 구체적 숫자
6. **키워드**: 마케팅 카피 핵심 키워드

## 품질 기준
- 구체적이고 검증 가능한 데이터 포함
- 페인포인트는 추상적이 아닌 구체적 상황 묘사
- 카피 패턴에 바로 활용할 수 있는 형태로 정리
